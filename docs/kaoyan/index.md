# 考研

统考备考与录取去向，按毕业届排列。现有 **12** 篇。2023 届覆盖艺术、心理、法学、社科和工科等方向；2024 届之后计算机方向开始补录，其它学院仍欢迎投稿。

各篇详略不同，有的偏复习节奏和资料，有的偏择校与复试。年份越近，考纲和竞争格局越有参考价值。

想写自己的考研经历，见 [贡献](../contribute.md)。
