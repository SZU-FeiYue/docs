# 保研

推免、夏令营、预推免和直博的记录，按毕业届排列。现有 **24** 篇：计软占大多数，另有物光、高研院等。去向包括清北华五、中科院，以及本校和深圳校区的实验室。

比较时建议对齐「申请当年」的成绩与产出，而不是毕业时的最终简历。夏令营、九推和导师联系的时间点，往往比最终学校名字更值得看。
