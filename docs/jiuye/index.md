# 就业

实习、校招和转正记录，按毕业届排列。现有 **9** 篇，目前以计算机、电子信息方向的技术岗位为主，去向包括字节、腾讯、量化机构和安全厂商。

可以对照：什么时候开始实习、投了哪些公司、面试怎么准备、为什么接受或放弃某个 offer。岗位要求变化快，近两届比更早的案例更贴近现在的节奏。
