# 留学

出境读硕、读博的申请记录，按毕业届排列。现有 **16** 篇，以计算机相关专业为主，去向集中在港校、新加坡、英美和部分北美项目。

读的时候可以同时看三件事：申请时的背景、投了哪些项目、最后为什么去这一所。套磁、选校和奖学金信息因人而异，适合当时间线和决策参考，不宜直接复用名单。

想写自己的申请季，见 [贡献指南](../index.md#contribute)。术语见 [术语表](../index.md#appendix)。
